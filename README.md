# Qyvaria Engineering Corpus & Public Archive

> **Official open-access repository, knowledge base, and software architecture ledger engineered and maintained by Jan Havlásek.**

Welcome to the central portal housing my lifetime work across software engineering, AI runtime development, operating system architecture, game engine optimizations, theoretical models, and technical documentation. 

This repository exists to make my discoveries, code, and practical implementations freely accessible to developers, researchers, and the open-source community.

---

## 🏛 Project Index & Systems Directory

### 🤖 Autonomous Systems & AI Architecture
* **`qyvaria.py` Kernel**: A single-file, deterministic Python runtime and multi-agent orchestration engine built for local-first, zero-dependency execution.
* **AI Orchestration Frameworks**: Custom prompt pipelines, multi-agent simulation runtimes, and local LLM integration tools.

### 💻 Developer Environments & Workbenches
* **Qyvaria OS & Browser OS**: Electron and Chromium-based developer environments featuring integrated AI BIOS tooling (`Qyvaria Com`), code editing workspaces, and system monitoring.
* **QyLab**: Multi-agent training modules and sandbox simulation environments designed for offline desktop setups.

### 🎮 Game Systems & Simulation Optimization
* **Qyvaria Organic Engine**: High-performance optimization mods for Paradox Interactive Clausewitz/Jomini engines, delivering native pulse culling, decision-tree enhancements, and AI behavior upgrades.
* **Experimental Game Systems**: Original mechanics, space 4X architectural blueprints, and simulation scripts built in Godot and custom environments.

### 📚 Research, Specifications & Theoretical Work
* **Technical Books & Encyclopedias**: Original manuals, system specs, and architectural documentation covering single-file kernel design, prompt engineering, and autonomous agent loops.
